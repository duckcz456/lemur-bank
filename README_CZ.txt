LEMUR BANK – Windows / Microsoft Store příprava

CO JE V BALÍČKU
- index.html: funkční demo aplikace
- manifest.webmanifest: PWA manifest
- sw.js: offline cache
- icons/: ikony 192 a 512 px

JAK SPUSTIT
1. Rozbal ZIP do složky.
2. Otevři index.html v Edge nebo Chrome.
3. Pro instalaci jako samostatná PWA musí být aplikace dostupná přes HTTPS (ne pouze jako lokální soubor).
4. Po zveřejnění na HTTPS otevři web v Microsoft Edge a použij nabídku Aplikace > Nainstalovat tento web jako aplikaci.

MICROSOFT STORE
Tento balíček zatím NENÍ MSIX/MSIXBUNDLE a není publikovaný v Microsoft Store.
Podle dokumentace Microsoftu je pro webovou aplikaci vhodná cesta PWA: aplikaci je potřeba hostovat přes HTTPS, zaregistrovat název aplikace v Partner Center a vytvořit Store balíček například pomocí PWABuilder. Partner Center účet a publikaci musí řešit dospělý/rodič s oprávněným účtem. Schválení Microsoftem není zaručeno.

DŮLEŽITÉ
LEMUR BANK je pouze simulátor s virtuálními částkami. Není bankou, nepřijímá vklady a neprovádí skutečné platby. Do aplikace nezadávej reálné bankovní údaje.
